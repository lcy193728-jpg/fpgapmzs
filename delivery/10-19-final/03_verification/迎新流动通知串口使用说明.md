# 迎新/应急流动通知串口使用说明

## 硬件与串口参数

- 使用开发板板载 CH340 USB 转串口。
- FPGA RX：F12；FPGA TX：D12。
- 串口参数：115200 波特率、8 数据位、无校验、1 停止位（8N1）。
- 串口只控制迎新和应急场景的底部流动通知，不改变图片、音频、马赛克、
  应急类型、中央告警信息、计时和疏散箭头。

## 使用方法

1. 安装 Python 3。
2. 在命令行执行 `pip install pyserial`。
3. 双击 `tools/启动迎新串口上位机.bat`，或运行 `python tools/welcome_uart_gui.py`。
4. 选择 CH340 对应 COM 口，填写通知内容后点击“全部应用”。

迎新和应急均支持修改通知内容、滚动速度、暂停/继续，以及恢复默认通知。新配置采用小鹅通第九讲的
toggle 跨时钟同步和帧边界提交方法，不会在一帧中途换字。当前配置保存在 FPGA 运行寄存器中，
断电后恢复默认值。

## 字库限制

为了控制 EG4S20 的 BRAM 和布线压力，本版使用 45 字预置字典，最多显示 32 字。软件会在发送前
检查不支持的字符。字库为：

`空格 迎新报到流程签领卡入住军训物资热烈欢同学校园通知请前往体育馆办理手续注意安全今日明天开始`

## 协议

接收帧：`A5 5A CMD LEN PAYLOAD... CRC`，CRC 为 CMD、LEN 和全部 PAYLOAD 字节异或。

- `01`：设置文字，PAYLOAD 为 1～32 个字形编号，按显示顺序逆序发送（配套上位机已自动处理）。
- `02`：设置速度，PAYLOAD 为 1～30，表示每移动 1 像素间隔多少帧。
- `03`：暂停控制，0 继续、1 暂停。
- `04`：恢复默认，无 PAYLOAD。

FPGA 回执：`A5 5A (80|CMD) 01 STATUS CRC`，STATUS=0 表示成功。

应急通知命令使用同一帧格式和同一 UART：

- `11`：设置应急底部文字，1～32 个应急字形编号，逆序发送。
- `12`：设置应急滚动速度，1～30 帧/像素。
- `13`：暂停控制，0 继续、1 暂停。
- `14`：关闭自定义内容，恢复四类应急各自原有的默认通知。

应急模式复用现有 116 字字库，不新增字模 BRAM。启用自定义后四种应急类型共用所设置的
底部通知；点击“恢复分类默认”后，火灾、地震、恶劣天气和临时疏散重新显示各自原文案。
