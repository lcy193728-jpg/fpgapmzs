# 10-15 物理实现驱动的候选筛选记录

## 目标与边界

本轮只尝试不改变 HDMI 显示、按键交互、音频、SDRAM、场景切换与 OSD 效果的等价优化。依据小鹅通资料中的增量开发原则，采用“局部证明/专项仿真 → TD 门级映射 → 固定 seed 布局布线 → 不收益即撤回”的闭环，不用 RTL 行数或主观推断代替器件结果。

稳定对照为 `artifacts/pic_sdram_audio_mosaic_logic_lp_1014.bit`：TD 6.2 seed=59，LUT 16350、REG 7620、LE 17197、slices 8848（90.29%）、BRAM9K 40、BRAM32K 8、DSP 14，SWNS +0.102 ns、HWNS +0.020 ns；门级 LUT 8722、门级 slices 3623。

## 候选一：抢答排序分数共享查表

思路是保留已有固定四路排序网络，只把四组排序后分数多路器改成“排序队号→原始分数”的共享查找。四队分数与排名位置共 5184 项逐项等价检查通过，`tb_quiz_ranking` 通过。

TD 门级 LUT 为 8892，比对照增加 170。该写法在当前综合器上没有得到预期共享，反而改变了原排序网络的局部优化结构，故在布局布线前撤回。

## 候选二：由排序键恢复分数

排序键已经包含补码分数和同分队号信息，因此尝试由键恢复排名分数，删除显式分数选择器。5184 项逐项等价检查及 `tb_quiz_ranking` 均通过。

TD 门级 LUT 8724（+2）、slices 3632（+9）。当前器件最终切片占用已超过 90%，切片增加比极小的逻辑形式简化更不利，因此撤回。

## 候选三：消隐期冻结显示坐标

`display_adjust` 的 RGB 输入已经在 `de_i=0` 时保持。本候选让 x/y 输入寄存器共用同一有效像素使能，以阻断消隐期递增坐标在 HUD、排名和转场几何网络中的翻转。专项测试覆盖：

- 消隐期 RGB 与 x/y 寄存器保持；
- 首个及连续有效像素的数据/坐标同拍；
- 同步和数据有效信号延迟不变。

行为测试通过，但物理结果恶化：

| 指标 | 稳定对照 | 坐标冻结候选 | 变化 |
|---|---:|---:|---:|
| 门级 LUT | 8722 | 8969 | +247 |
| 门级 slices | 3623 | 3632 | +9 |
| 最终 LUT | 16350 | 16637 | +287 |
| 最终 REG | 7620 | 7618 | -2 |
| 最终 LE | 17197 | 17417 | +220 |
| SWNS | +0.102 ns | -0.396 ns | -0.498 ns |
| 建立违例端点 | 0 | 7 | +7 |

原因是 x/y 属于高扇出几何网络，给寄存器增加 CE 会引入反馈选择和共享控制布线；综合器还会重构下游比较逻辑。节省的无效翻转不足以抵消新增 LUT、连线电容和时序压力。该候选已完全撤回，测试与失败位流也已移除。

## 结论与下一步

本轮没有改变交付功能，也没有生成新的可烧录版本。继续使用稳定的 `pic_sdram_audio_mosaic_logic_lp_1014.bit`，SHA-256 为 `7472DF591F6033341BA5F7C2188A7E4C39FC1D117DD54DB01201FA3E6B32BBAC`。

下一阶段只筛选以下低风险方向：

1. 利用现有 BRAM/FIFO 原生读写使能关闭非显示窗或非活动场景的存储访问，避免在高扇出数据路径上新增 CE。
2. 在模块入口用低扇出场景状态锁定局部计数器和地址发生器，而不是冻结全局像素坐标。
3. 对仍存在的常数除法、重复边界比较先做穷举等价验证，再检查门级 LUT、最终 slices 和 SWNS；任何一个关键指标明显变差即撤回。
4. 保持 PLL、SDRAM 控制器、HDMI PHY 和跨时钟域结构不动，所有模式切换继续在帧边界原子提交。

这套筛选方式本身可用于比赛报告：优化不是单纯减少代码，而是以 FPGA 映射、布线、时序和活动范围共同决定是否接收。
