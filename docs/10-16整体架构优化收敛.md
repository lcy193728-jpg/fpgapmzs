# 10-16 整体架构优化收敛

## 1. 最终架构边界

当前工程固定为五层：

1. **稳定驱动层**：PLL、SDRAM 加密控制器、HDMI 加密核、异步 FIFO。遵循小鹅通
   第一课要求，不修改时钟频率、控制器内部逻辑和跨域 FIFO。
2. **存储数据面**：FAT32/分区素材读取、BMP/WAV 仲裁、双缓冲原子提交、缩放写回。
3. **帧级控制面**：场景选择、切图请求、写完成 toggle、首帧有效门控、帧边界提交。
4. **像素流水面**：马赛克、菜单/迎新/抢答/会议/应急 OSD、音频可视化、显示调节。
5. **验收面**：专项仿真、门级快速筛选、固定 seed=59 布局布线、QoR 九项门禁。

这个划分落实了小鹅通的三个核心原则：跨域事件用 toggle/2FF，显示状态只在帧边界
提交，底层稳定 IP 与高频变化的应用层隔离。

## 2. 已经落地、无需重复修改的优化

- 首帧有效门控、场景加载保护和抢答结束完整帧提交，避免冷启动和切场残帧。
- OSD 字库三场景共享一片 ROM，读使能只在有效字形窗口打开。
- `bmp_scale` 三块行缓存 BRAM 只在实际读取状态使能；空闲、旁路和等待阶段不读。
- 迎新马赛克 BRAM 在模式关闭时完全不读写；开启后每 16 像素读一次、每 16 行写一行。
- 音频可视化 BRAM 读口只在可视化有效行窗口打开，消隐期关闭。
- DDS 在静音/IDLE段冻结相位；应急鸣停段不进行无效波形推进。
- `display_adjust` 消隐期保持 RGB，固定比例运算使用移位加法，避免通用乘除法器。
- 图片坏头、截断、超时和尺寸不匹配均有防护，不提交未完成帧。
- SDC 已清除失效层次约束，真实单比特 CDC 保留同步器/false-path语义。

## 3. 本轮架构候选结论

### 3.1 有效位与 payload 复位分离——淘汰

尝试保留 HS/VS/DE 复位、取消菜单层 RGB/坐标移位链复位。有效像素语义不变，但安路
TD 对原带复位移位链的合并更好。候选门级 LUT 由基准约 8741 增至 8786，门级切片
由 3632 增至 3653，因此未扩展到其它像素层并已回退。

### 3.2 应急层死变量源码清理——淘汰

删除无消费者的 `large_q`、`digit_hit` 和 `integer di` 后，逻辑功能不变，但映射结果
跳到更差的优化解：门级 LUT 8981，门级建立 WNS -2.743ns。候选已回退。结论是当前
高占用工程不能用 RTL 行数判断优化，必须以最终物理结果判断。

## 4. 当前物理基线

- LUT：16365 / 19600（83.49%）
- REG：7613 / 19600（38.84%）
- LE：17084
- Slice：8822 / 9800（90.02%）
- BRAM9K：40 / 64；BRAM32K：8 / 16；DSP：14 / 29
- 固定 seed=59：Setup WNS `+0.121ns`，Hold WNS `+0.020ns`
- QoR 门禁：9/9 通过

当前第一瓶颈是 **Slice 装箱与局部布线**，不是寄存器、BRAM或DSP数量。任何只降低
RTL复杂度、却增加控制集或宽多路器的方案，都可能使切片占用和时序反而变差。

## 5. 后续唯一值得做的架构升级

### 四-bank 素材缓存（独立版本，不直接覆盖当前展示版）

小鹅通第八讲的四-bank + loader/reader 分离，能减少重复 TF 卡加载、提升切图即时性并
降低 SD/SDRAM 写侧的平均活动率。但它会改动素材生命周期、地址管理和跨域提交，必须
作为独立分支实施，不能在当前已验证展示版上原地替换。

进入条件：

1. 先冻结当前 BIT 和场景回归结果；
2. 建立四-bank 地址不重叠形式检查；
3. loader 写非显示 bank，reader 只在 frame_start 原子切换；
4. 加入 FIFO overflow/underflow、超时和错误码；
5. 完整跑冷启动、坏图、切场、抢答结束、音频和断电固化回归；
6. 最终 Slice 不高于 8822 且 Setup/Hold WNS 均非负，才允许替换主线。

在不允许改变当前功能效果、也不允许增加物理资源风险的前提下，当前主线已经达到可
证明的优化边界；继续对小组合逻辑做手工改写不是升级，只是在改变布局随机性。
